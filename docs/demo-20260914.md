# Demo 现场速查

Windows 打开 **PowerShell**；macOS 打开 **终端**。只需 SSH 和浏览器，无需安装 agent 或拷贝密钥。密码见单独提供的消息。

## ① 登录并建立网页通道 · 在笔记本执行

```bash
ssh -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -L 127.0.0.1:18789:127.0.0.1:18789 root@39.96.85.42
```

首次连接核对指纹后输入 `yes`，再输入密码（屏幕不显示字符）。**这个窗口保持打开。** 两台笔记本各执行一次即可。

## ② 打开 OpenClaw 网页 · 在登录后的窗口执行

```bash
ca-demo web
```

复制输出的**完整网址**到笔记本浏览器，进入 **Chat**，发送「你好」。

## ③ 终端对话 · 在登录后的窗口执行

| 想用哪个 | 输入命令 |
| --- | --- |
| OpenClaw | `ca-demo openclaw` |
| Codex | `ca-demo codex` |

输入文字，回车发送。按 `Ctrl+C` 退出 agent 界面；若提示，再按一次。

## ④ 演示 TDX SKILL · 粘贴到 agent 对话框

OpenClaw（网页或终端）：

```text
请使用 tdx-remote-attestation skill，实际执行远程认证，用中文简要解释硬件可信度及 MRTD、RTMR、UKI 度量。失败请如实报告。
```

Codex：

```text
请使用 $tdx-remote-attestation 实际执行远程认证，用中文简要解释硬件可信度及 TDX 度量。失败请如实报告。
```

若询问是否允许执行认证命令，检查后允许。结果以实际工具输出为准；本次认证覆盖 agent 所在 TDX 实例，不覆盖百炼模型推理。

## 遇到问题

| 现象 | 快速处理 |
| --- | --- |
| SSH 超时 | 换手机热点试试；会场网络需允许 TCP 22。 |
| 端口被占用 | 关闭本机旧的通道窗口，再执行第 ① 步。 |
| 网页打不开或未授权 | 保持第 ① 步窗口打开；在部署机重新运行 `ca-demo web`，复制完整网址。 |
